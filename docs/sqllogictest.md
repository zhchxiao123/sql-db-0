其中 `vendor/` 下 3 个文件逐字取自固定 commit 的上游仓库,其余为本项目自写的
sqllogictest 格式测试文件,覆盖引擎当前支持的 SQL 子集。

```
sqllogictest/tests/000_basic.test
sqllogictest/tests/010_expressions.test
sqllogictest/tests/020_aggregates.test
sqllogictest/tests/030_views_indexes.test
sqllogictest/tests/040_errors.test
sqllogictest/tests/050_ordering.test
sqllogictest/tests/vendor/slt_lang_droptable.test
sqllogictest/tests/vendor/slt_lang_dropindex.test
sqllogictest/tests/vendor/slt_lang_dropview.test
```

运行方式:`make run`(等价 `python3 -m sqldb0.runner sqllogictest/tests`)。
